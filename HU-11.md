# HU-11 - Registrar un nuevo neumático

**Historia**: Como Editor o Administrador, quiero dar de alta un nuevo neumático en el sistema, registrando sus características técnicas, su estado actual y, de forma opcional, su número de serie, para incorporarlo a la gestión de activos de la empresa.

**Descripción**: Al registrarse un neumático deben indicarse su número de serie (opcional), marca, estado inicial, tipo de eje de origen (dirección/tracción/arrastre/auxilio), cantidad de recapados y comentarios opcionales, además si es nuevo se debe indicar el proveedor a quien se le adquirió.

**Criterios de Aceptación**: 

- Dado que un Editor o Administrador completa el formulario de alta con un número de serie, marca, estado inicial, kilometraje actual, kilometraje desde el último mantenimiento, tipo de origen, cantidad de recapados, comentarios y un proveedor (en caso de ser nuevo); cuando confirma la operación, entonces el sistema debe registrar el neumático. Si el estado es “nuevo”, se debe generar automáticamente el primer evento de su historial de trazabilidad (evento de compra). El neumático debe quedar “en espera” de que el usuario haga una operación con el mismo (asignarlo a una unidad de transporte, enviarlo a un centro de almacenamiento o servicio de reparación).
- Dado que se intenta registrar un neumático completando sus campos de forma válida, antes de confirmar la acción, el sistema debe lanzar una advertencia con un claro mensaje de que el número de serie no se podrá cambiar una vez confirmada la acción.
- Dado que se intenta registrar un neumático con un número de serie ya existente en el sistema, cuando se confirma el alta, entonces el sistema debe rechazar la operación e informar el motivo.
- Dado que se intenta registrar un neumático sin completar datos obligatorios, entonces el sistema debe impedir el envío del formulario.
- Dado que se intenta registrar un neumático completando los datos obligatorios, pero omitiendo el número de serie, el neumático debe ser registrado correctamente.
- Dado que un usuario con nivel de acceso Lector intenta acceder a esta funcionalidad, entonces el sistema debe denegar el acceso a dicha pantalla o funcionalidad.

**Notas / Supuestos**: Esta historia asume que el conjunto de estados posibles de un neumático son: Nuevo, nuevo usado, hombros, recapado, recapado usado, recapado sin garantía, de baja. Estos estados son los solicitados por el cliente y están sujetos a ampliación. Se destaca que el número de serie es opcional, por el hecho de que algunos neumáticos de marcas genéricas carecen de este atributo.
